# Local web fonts

Both original variable fonts were retrieved from the official Google Fonts repository and converted to WOFF2 without subsetting or changing their glyph outlines. Both SIL Open Font License notices are retained beside the fonts and embedded in the self-contained review HTML.

| Font | Source | Verified source Git blob |
| --- | --- | --- |
| Bodoni Moda | https://github.com/google/fonts/blob/main/ofl/bodonimoda/BodoniModa%5Bopsz%2Cwght%5D.ttf | `c5d582f8003ae692761dd8e9ce69de23cb9fea53` |
| Inter | https://github.com/google/fonts/blob/main/ofl/inter/Inter%5Bopsz%2Cwght%5D.ttf | `047c92f6e2212473dc436020afed689527076d44` |

The bundled fonts cover the English and French text. Chinese uses explicit Simplified/Traditional system-font stacks: Songti for display text and PingFang/YaHei/JhengHei for body text. Chinese letterspacing is set independently of the Latin display tracking.
